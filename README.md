# 📊 E-commerce Analytics Dashboard

## 📌 Project Overview
This project is an end-to-end data analytics solution designed to analyze e-commerce sales data and generate meaningful business insights. It involves data extraction, cleaning, analysis, and visualization using industry-standard tools.

## 🚀 Objectives
- Analyze sales performance across categories, regions, and products
- Identify top-performing and low-performing products
- Understand customer purchasing behavior
- Evaluate the impact of discounts on profit
- Build an interactive dashboard for decision-making

---

## 🛠️ Tech Stack
- **SQL Server** – Data extraction and querying  
- **Python** – Data cleaning, transformation, and analysis  
- **Tableau** – Data visualization and dashboard creation  

---

## 📂 Dataset
- Sample Superstore Dataset (CSV format)
- Contains:
  - Order Details
  - Customer Information
  - Product Data
  - Sales, Profit, Discount, Region

---

## 🔄 Project Workflow

### 1️⃣ Data Extraction (SQL)
- Imported dataset into SQL Server
- Performed queries to filter and analyze data

### 2️⃣ Data Cleaning & Analysis (Python)
- Handled missing values
- Converted date columns
- Created new features (Month, Year)
- Performed:
  - Sales trend analysis  
  - Profitability analysis  
  - Customer segmentation  
  - Shipping performance  

### 3️⃣ Data Visualization (Tableau)
- Built interactive dashboard with:
  - Sales Trend (Line Chart)
  - Category-wise Sales (Bar Chart)
  - Region-wise Performance
  - Top 10 Products
- Added filters for dynamic interaction
- Created KPIs:
  - Total Sales
  - Total Profit
  - Total Orders
  - Profit Margin

---

## 📊 Key Insights
- Sales peak during the last quarter (Q4)
- Technology category generates highest revenue
- Some products have high sales but low profit due to discounts
- West region performs best in terms of sales
